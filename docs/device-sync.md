# 序点设备同步

序点只有一种同步方式：所有设备通过**序点同步网关**交换端到端加密的数据。网关只保存密文，看不到笔记内容。

## 第一台设备：粘贴一次服务器邀请

1. 在网关管理页（见[部署指南](../node/gateway-deploy/README.md)）点「生成七天有效邀请」，复制完整链接。
2. 在第一台设备打开「设置 → 设备与同步」，把链接粘贴到「连接同步服务器」，点「连接」。
   Android 浏览器里可直接点「在序点中打开」。

每份邀请只能开通一个资料库，只需要用这一次。

## 其他设备：从已连接的设备加入

1. 在任意一台已连接的设备上打开「设置 → 设备与同步」，点「添加设备」。页面显示二维码和一条加入链接。
2. 在新设备打开「设置 → 设备与同步」：
   - 手机点「扫一扫」扫描二维码；
   - 电脑把加入链接复制过来，粘贴后点「连接」。
3. 新设备显示「已连接同步服务器」即完成，之后自动同步，不需要再做任何事。

两台设备**不需要在同一个网络**，只要都能访问同步网关。加入链接 10 分钟内有效、只能使用一次，
请只发给自己的设备。链接里的一次性密钥只在两台设备之间传递，网关只转交加密的配对消息，
既不能冒充新设备，也拿不到资料库密钥。

新设备上原有的便签、事项、标签和附件会保留，并与资料库合并。已经属于另一个同步空间的设备不能直接加入。

## 日常使用

- 修改后自动上传，打开应用时每 30 秒检查一次其他设备的修改；也可以点「立即同步」。
- 「同步附件和录音」控制原文件传输，会使用移动数据，分块续传。
- 手机只在前台同步，回到前台后自动补齐。
- 「撤销」某台设备后，它不再收到新的同步数据；不会远程删除它已有的数据。
- 加入时若网络中断导致没有登记到服务器，新设备会显示「重试连接」。
- 恢复备份或出现成员冲突时，页面会出现「恢复同步」，按提示处理。

重要数据仍需独立备份。

## 从旧版本升级

- 旧版本的局域网直连、自建 Syncthing 节点和手动节点地址入口已移除。已连接网关的设备无需任何操作。
- 只用局域网配对过、还没连网关的设备：在其中一台粘贴服务器邀请，其余设备在它上面「添加设备」加入即可。
- 「添加设备」需要更新后的同步网关；旧网关会提示「同步服务器版本过旧」。
