# 局域网与 Syncthing 同步

## 首次配对

1. 手机和电脑接入同一局域网，打开「设置 → 同步 → 连接手机或电脑」。
2. 电脑点击「等待设备连接」，手机点击「扫一扫」扫描电脑的二维码。
   也可让手机等待连接，把手机显示的 `IP:端口` 填入电脑，点击「连接此地址」。
3. 核对两端显示的短码一致，在等待连接的一端点击「短码一致，允许同步」。
4. 两端开启「局域网自动双向同步」，随后修改会自动交换，无需重复配对。

配对期间保持页面打开；配对完成后可以离开页面。手机同步时需保持应用在前台。
首次扫码需要相机权限，iOS 需要允许本地网络访问；电脑防火墙需允许本地连接。
设备的局域网地址改变后，可在连接页重新连接。不要用公网地址代替局域网邀请。

## 通过自己的 Syncthing 节点跨网同步

先完成上述局域网配对，以便两台设备共享序点的加密身份。
然后在每台客户端的「Syncthing 跨网同步」中各配置一次：

1. 在常在线的电脑或服务器安装并运行官方 Syncthing。客户端已经内嵌引擎。
   在节点本机打开 `http://127.0.0.1:8384`，设置可写、持久保存的默认文件夹路径。
   容器部署时持久化配置和数据目录，以免重建后丢失设备身份或加密副本。
2. 推荐将节点与客户端加入同一 VPN。管理接口仅允许本机、受信内网或 VPN 访问，
   设置用户名和强密码；使用 HTTPS 时需有效证书。不要把管理端口映射到公网。
   在 Syncthing「操作 → 设置 → 常规」中取得 API Key。
   本页填写 **Syncthing 管理 API 地址**，例如 `http://192.168.1.10:8384`，
   或通过 VPN 可达且有有效证书的 `https://sync.example.com:8384`。
3. 首次填入管理 API Key，点击「保存并授权」，开启跨网同步。
   应用自动登记本机 Syncthing 设备并共享本资料库的加密目录。
4. 另一台已配对设备配置同一 Syncthing 节点。节点常在线时，客户端无需同时在线。

不带协议的地址按 HTTPS 处理。API Key 可以修改远端配置，管理连接应保持私网可达，
无需为它单独开放公网 HTTPS 端口。当前客户端每轮同步仍会通过 API 核对共享授权，
并非只在首次配置时需要；只开放数据传输端口不能完成当前功能。
HTTP 仅允许回环、RFC1918 私网 IPv4 或 IPv6 ULA；其他地址（包括 VPN 的 `100.64.0.0/10`
地址）需使用有效 HTTPS。地址不能带路径前缀。API Key 仅保存在客户端安全存储，
同一地址留空可保留已存密钥。
不要把 API Key 发到聊天、提交到仓库，或把它当作序点的设备配对密钥。

管理端口与文件传输端口不同：这里不能填 `22000` 代替管理地址。
节点的 Syncthing 传输连接也必须可用；只开放管理页面并不能传输文件。
应用使用节点的监听配置和动态发现，不会把 API Key 放进传输地址。

### 最小端口暴露

| 端口（默认值） | 用途 | 开放范围 |
| --- | --- | --- |
| 22000/TCP | 数据传输 | 全部走 VPN 时无须公网映射；需要公网 TCP 直连时才映射 |
| 22000/UDP | QUIC 数据传输 | 需要 QUIC 直连时按需开放；仅用 TCP 可不开放 |
| 21027/UDP | 局域网设备发现 | 仅局域网，不做公网映射 |
| 8384/TCP | 管理界面与 REST API | 仅本机、受信内网或 VPN，不向公网开放 |

严格控制端口时关闭不需要的 UPnP/NAT-PMP 自动映射。支持中继的传输连接也可以不做
入站映射，但当前序点的管理 API 仍需通过私网可达。自定义端口以实际监听配置为准。
当前自动生成的 TCP 直连地址使用管理地址的主机名和节点的监听端口；若公网直连，
保持内外传输端口一致。管理主机与传输主机不同时，该地址可能不可达，需依赖发现或中继。

安装与初始化步骤见 [Syncthing 官方入门](https://docs.syncthing.net/intro/getting-started.html)，
网络规则见 [官方防火墙说明](https://docs.syncthing.net/users/firewall.html)；
管理接口默认监听与访问限制见 [GUI/API 监听地址说明](https://docs.syncthing.net/users/guilisten.html)。

新共享目录位于节点配置的默认目录下的 `SeqPoint/seqpoint-…`；
没有默认目录时使用 Syncthing 服务用户的主目录。请确保该位置可写，容器部署时持久化该目录。
目录里只存序点加密后的同步数据，不是可直接打开的原始笔记数据库。
无需为此功能部署序点 HTTPS 中转节点，也无需手工复制 `node.json`。

「同步附件和录音」控制原文件传输，也会使用移动网络；文字内容按正常同步处理。
暂停同步会停止当前原生传输，恢复后继续交换。手机进入后台会暂停，回到前台后继续。
恢复备份、身份冲突或撤销设备时，先按「恢复同步／高级同步设置」中的提示处理。
本机已上传不代表另一端已接收；重要数据仍需独立备份。
