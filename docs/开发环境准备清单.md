### 步骤 A：安装 Android Studio 与 SDK（zsh）

```bash
brew install --cask android-studio
```

打开 Android Studio → 首次向导按默认安装 SDK → **More Actions → SDK Manager** 勾选并安装：
- SDK Platforms：Android 15（API 35）
- SDK Tools：Android SDK Build-Tools、Android SDK Platform-Tools、Android SDK Command-line Tools (latest)、Android Emulator、NDK (Side by side)、CMake

然后在 `~/.zshrc` 追加并重开终端：

```bash
export ANDROID_HOME="$HOME/Library/Android/sdk"
export PATH="$PATH:$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin"
export LANG=en_US.UTF-8
```

接受许可并复查：

```bash
flutter doctor --android-licenses
flutter doctor -v
```

### 步骤 B：Android 手机接入

1. 手机：设置 → 关于手机 → 连点"版本号"7 次开启开发者选项 → 开发者选项中打开"USB 调试"（推荐同时打开"无线调试"）。
2. 数据线连接 Mac，手机上允许调试授权。
3. 验证：`adb devices` 应列出设备且状态为 `device`；`flutter devices` 能看到该手机。

（可选）创建一个 API 35 的模拟器：Android Studio → Device Manager → Create Device。

## 二、Windows 开发机（用于 Windows 桌面端构建与测试）

按顺序执行（PowerShell，管理员权限）：

```powershell
winget install -e --id Git.Git
winget install -e --id Microsoft.VisualStudio.2022.Community --override "--add Microsoft.VisualStudio.Workload.NativeDesktop --includeRecommended --passive"
winget install -e --id Google.AndroidStudio
git clone -b stable https://github.com/flutter/flutter.git C:\dev\flutter
[Environment]::SetEnvironmentVariable('Path', $env:Path + ';C:\dev\flutter\bin', 'User')
start ms-settings:developers
```

说明：
- Visual Studio 必须包含 **"使用 C++ 的桌面开发"** 工作负载（含 Windows 10/11 SDK），否则 `flutter build windows` 失败。
- `ms-settings:developers` 打开后启用 **开发者模式**（Flutter 插件需要符号链接权限）。
- Android Studio 在 Windows 上同样按步骤 A 勾选 SDK 组件；Java 使用 Android Studio 自带的 JBR 即可。
- 重开 PowerShell 后运行 `flutter doctor -v` 复查。
