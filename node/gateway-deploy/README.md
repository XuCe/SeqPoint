# 在群晖运行序点同步网关

一个容器保存多个资料库的加密数据。使用普通 Docker 数据卷即可。现有 Syncthing 容器、8384 管理端口和共享目录都可以继续独立使用。

## 首次部署

1. 解压交付包。在 DSM「容器管理器 → 映像 → 新增 → 从文件添加」导入一个 tar。Intel / AMD 群晖用 `amd64`，64 位 ARM 群晖用 `arm64`。NAS 上运行 `uname -m` 可确认，分别对应 `x86_64` 和 `aarch64`。
2. 在 File Station 建立项目目录，例如 `/volume2/docker/seqpoint-gateway`。放入 `compose.yaml`。填写用户可访问的 `GATEWAY_ORIGIN`，例如 `http://192.168.2.191:8385` 或 `http://sync.example.com:8385`，也支持 HTTPS。地址末尾不要带斜线。`GATEWAY_ADMIN_PASSWORD` 填至少 8 字节（英文或数字为 8 位）的管理密码。
3. 在「容器管理器 → 项目 → 新增」选择该目录，使用现有 Compose 文件并启动。网关数据保存在项目的 `gateway_data` 命名卷，更新时沿用相同项目名和卷。通过 SSH 也可以在项目目录运行 `docker compose up -d`。
4. HTTP 可直接访问 `http://192.168.2.191:8385/invite`，使用域名时需保证域名解析和端口可达。若使用 HTTPS，在 DSM「控制面板 → 登录门户 → 高级 → 反向代理」将 HTTPS 入口转发到 HTTP `192.168.2.191:8385` 并绑定有效证书。管理员入口 8386 仅供可信内网访问。

HTTP 会明文传输邀请、连接凭据和请求信息，适合可信内网。笔记内容仍由客户端加密。公网使用建议配置 HTTPS。

更新本版时，需要同时更新网关镜像和序点客户端。旧客户端会拒绝 HTTP 邀请；新客户端的「添加设备」需要带配对信箱（`/v1/pair`）的网关镜像。更新容器时沿用已有数据卷或目录挂载。

## 发出第一份邀请

在可信内网打开 `http://192.168.2.191:8386`，用户名为 `admin`，密码为 Compose 文件中设置的值。点「生成七天有效邀请」并复制完整链接。未使用的邀请可取消；一次邀请开通一个资料库。同一台设备在网络中断后可以重试。空间默认 1 GiB，可调整配额或暂停。

用户安装包含同步网关功能的序点客户端后打开邀请，确认域名并启用。Android 浏览器可点「在序点中打开」。其他支持协议唤起的平台可点「复制邀请并打开序点」，在 App 点「粘贴刚复制的邀请」，核对域名后确认。HTTP 页面可选中页面上的完整邀请链接手动复制。浏览器拦截跳转时，在「设置 → 同步 → 启用云同步」粘贴完整链接即可。更多设备在已连接的设备上点「添加设备」，扫码或粘贴加入链接即可，不需要在同一网络，用户无需再向你领取邀请。加入链接经网关的临时配对信箱转交（只在内存保存 10 分钟），网关看不到资料库密钥。

若发布方为该域名构建了手机关联链接，可以设置 `GATEWAY_ANDROID_SHA256` 为 Android 发布签名的冒号分隔 SHA-256 指纹，或设置 `GATEWAY_APPLE_TEAM` 为 Apple Team ID。网关自动在 `/.well-known/` 返回关联文件。对应版本的 App 和平台验证成功后，点击 HTTPS 邀请会直达确认页。

## 验收与备份

首机开通前新建一条笔记，开通后执行一次网关同步。第二台设备通过「添加设备」加入后，让首机同步最新成员状态并下线，再在第二台同步，检查笔记和附件（需开启附件同步）。撤销设备后，保留设备需联网提交撤销，节点随后拒绝被撤销设备的请求。停止网关写入后备份整个数据卷，包含注册表和所有密文。保留客户端安全备份以恢复解密密钥。

## 从源码生成离线包

在装有 Go 1.25+、Docker Buildx 的开发机运行 `bash node/gateway-deploy/package.sh /绝对路径/输出目录`。镜像内只包含网关二进制及数据目录，以非 root 用户运行。
